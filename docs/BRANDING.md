# Panduan brand: MAUNG by LIV (acuan Tahap 1 – tampilan)

Sumber: `docs/branding/brand-guideline.webp` (Core Brand Elements), `login-mockup.png` (halaman login), `logo-horizontal.webp`, `logo-stacked.webp`.

**MAUNG** = **M**arketing · **A**sset · **U**nified **N**etwork & **G**overnance — "by LIV".

## Palet warna
| Nama | Hex | Peran |
|---|---|---|
| LIV Navy | `#0B1F3B` | Warna utama: latar, header, elemen penting |
| Maung Charcoal | `#1F2937` | Sekunder: teks, panel, elemen UI |
| West Java Gold | `#F59E0B` | Aksen utama: highlight, CTA, ikon |
| Cloud White | `#F8FAFC` | Dasar: latar konten |
| Mountain Mist | `#94A3B8` | Pendukung: elemen sekunder dan border |

Grafik/status boleh memakai warna lain (hijau/merah/biru/ungu) selama selaras dengan palet di atas (saturasi dan kecerahan serumpun, aksen emas tetap jadi sorotan).

## Tipografi
- Primer (judul, tagline, display): **Playfair Display**
- Sekunder (UI & konten): **Inter**

## Elemen antarmuka (dari panduan)
- Header/top bar navy dengan menu aktif bergaris bawah emas.
- Tombol: **Utama** (emas, teks navy, ikon panah), **Sekunder** (navy), **Outline**, **Teks** (tautan dengan chevron).
- Pola visual: huruf M, kepala maung, jaringan teknologi; garis kontur gunung emas sebagai latar/aksen.

## Yang HARUS bisa diatur Admin (persyaratan)
Semua lewat **Admin → Pengaturan → Tampilan & Brand** tanpa deploy ulang:
1. **Logo** (horizontal untuk header/login, bisa juga versi tegak) — ukuran menyesuaikan otomatis.
2. **Tagline** ("Gerak Cepat, Kerja Tepat.").
3. **Teks halaman login** ("Satu Ekosistem. Dampak Lebih Besar untuk Jawa Barat dan Indonesia.").
4. Nama brand/perusahaan dan baris sub-judul ("Marketing • Asset • Unified Network & Governance").
5. Warna tema (primer, aksen, serta palet grafik) dengan nilai awal sesuai tabel di atas.
